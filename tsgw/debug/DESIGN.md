# Debug 任务大盘设计

## 页面与信息分区

`/debug` 观察当前实例的运行态资源，以上游 Debug 的诊断能力为覆盖基线，与上游 DebugPanel 和聊天生命周期独立。界面不提供历史目录、搜索筛选或手动选择采样。

| 分区 | 当前内容与语义 |
| --- | --- |
| 页头 | 品牌、浏览器时钟、快照新鲜度、关注信号数量、复制 JSON、新窗口返回工作区。复制包含全局快照、各会话资源／模型采样和本页观测数据，不包含完整会话目录。 |
| 六项概览 | 普通会话、子代理、执行总数、等待输入、驻留总数、全部 SSE；普通会话包含 fork 与已确认侧聊，前两项附各自执行数。没有有效快照时显示未知，不显示零。 |
| 左侧观测 | 关注信号、Debug／目录两路轮询、服务器资源。资源包括实例运行时间、alive／closing／starting wrapper、Agent SSE／全部 SSE、文件监听、idle／heartbeat 设置；终端数量／监听／脱离／退出／清理时间及连接页面明细可展开。页面明细保留浏览器、地址、holder 和各类流数量。 |
| 右侧家族网格 | 每家族一个外框，主会话和子代理同框，项目仅作头部元数据。同项目的不同主会话不合并；fork、侧聊独立成根并显示真实来源。多级子代理采用根家族加单层成员行，另列真实直接父关系。 |
| 会话资源行 | 身份／状态／profile、委派描述与父级、目录子代理状态、模型／provider／思考档位、项目路径／分支及各自采样时间；完整显示 wrapper、回收检查、MCP、SSE、保活 provider 和进程生命周期信息。 |

资源明细保留扩展 binding／bound／failed／none、pending prompt／queued message／tool／bash／compaction／retry／replacement／UI wait、启动次数及最近事件／命令。子代理运行记录保留 profile、resume、后台、取消请求、MCP 等待、直接父级和采样来源；父级通知保留子会话来源及等待时间。已采样父会话返回的非驻留子代理记录标为运行记录，不为其建立资源或额外采样。

桌面左栏宽 260px，左右区域分别滚动；资源区按容器宽度采用一／二／三列，末行利用余宽，家族成员无独立滚动区。1366／1440 桌面以两列为验收目标，宽屏可三列；手机按左侧观测、右侧资源的 DOM 顺序纵向阅读。家族顺序沿用宿主分组，不按轮询更新时间重排，不使用 dense 填充。

视觉为模块内独立的深色控制台：石墨蓝背景、分层面板、电青强调、紫色子代理、绿灯及橙红异常，保留品牌和 SVG 准星，不改变聊天主题。状态同时提供文字或无障碍标签；运行圆环仅用于宿主判定为 running 的驻留会话，等待、空闲、关闭及关系占位不显示。尊重减少动态效果、键盘焦点和手机无横向溢出；不靠缩字号、折叠资源事实或装饰占位提高密度。

## 数据来源与采样

| 既有只读接口 | 用途与更新方式 |
| --- | --- |
| `GET /api/agent/debug[?session=]` | 首次取全局摘要，之后在全部驻留 ID 间公平轮换详情。每 2 秒检查、最多一个 Debug 请求在途；稳定 N 个会话时每份详情约 2N 秒更新一次，慢请求和隐藏页会延长。摘要来自最近成功请求，详情按会话独立缓存服务端时钟、接收时间和失败状态。 |
| `GET /api/sessions` | 每次目录请求结束后等待 30 秒再到期读取，仅补名称、项目／分支、普通／子代理／fork／侧聊关系与持久化子代理状态。目录与 Debug 不是原子快照，历史条目不增加资源或采样。失败时保留旧目录并提示。 |
| `GET /api/agent/<id>?systemPrompt=0` | 每次资源查询至多触发一个串行状态 GET，仅提取 `state.model.{provider,id}`、`state.thinkingLevel` 及驻留状态；不使用默认模型或历史猜测。失败保留本会话旧采样，缺字段显示未知，未驻留返回 `running=false`。宿主响应仍有其他状态字段，本模块不缓存或复制这些字段。 |

隐藏页暂停发起轮询，恢复可见后检查；在途请求不叠加。Debug、目录及模型读取均有 5 秒请求取消时限。Debug 与目录各保留 24 个实测样本、耗时、在途／慢／失败、计数及下次检查时间；失败样本单独标记，不冒充成功耗时。本页协议与可见性来自浏览器，只描述这个观察页。

驻留集合以最近成功 Debug 摘要为准：服务器持有 wrapper 或 Agent 事件流即在集合内。各详情只归属于请求的会话，退出集合即清理资源与模型缓存；迟到回复和旧全局详情不能复活资源。未采样时使用本会话 summary 的回收检查与服务端时钟，详情到达后替换为其独立时钟，不借用其他会话采样。

## 重要边界

- 仅消费上述既有 GET，不新增或改变后端接口、字段、参数及行为。页面不发送任务命令、不启动冷会话、不续租、不开 EventSource、不读上下文历史，不向用户会话注入测试；宿主状态读取不更新最近命令或 idle。任何接口扩展须先取得用户明确确认。
- 驻留包含执行、等待输入、空闲和关闭中；无 wrapper、`running=false`、目录存在或消失均不能证明任务成功。普通任务完成数和完整时间线不从这些状态推断。非驻留父级仅为关系上下文，不显示自身旧资源／模型／等待采样，也不计入活动数量。
- 目录状态与实时运行状态分别标注。侧聊按目录关系识别并计入普通会话，不当作委派，也不创建来源父级占位；目录缺失时的身份限制见下节。
- 回收倒计时表示下次 idle 检查，不保证届时关闭；Stop 强制关闭单独提示。每会话仅一处回收检查数字与进度条，MCP 释放使用另一组真实时间，均以所属快照服务端时钟推算。
- MCP 服务器灯保留连接／错误／冲突／释放及配置问题；宿主灯读取 `mcp.active`，执行灯读取 `mcp.runActive`，两者相互独立，执行灯不代表正在调用 MCP 工具。状态除颜色外有实线／虚线／点线、短文字、提示及无障碍标签。
- SSE 只按完整非空 holder 归组为 `SSE ×N`；无 holder 的连接分别展示，每条连接的打开／连接／写出时间、来源、丢弃及积压仍可读。积压不证明浏览器卡死，正在建立连接时不将 listener 差异误判为泄漏。holder、地址与浏览器标签不是认证身份。
- 关注信号聚合已采样驻留详情的 listener 差异、扩展／provider／MCP 错误、配置问题和丢弃事件，并展示本页读取故障／慢请求。未采样、过期、未知和读取失败保留实际提示；“快照已更新”不等于实例全部健康。

## 当前数据缺口

- **角色信息依赖目录。** Debug 的 `subagent` 标志来自通知抑制，侧聊也可能为 true；目录未返回或缺少对应记录时无法准确区分侧聊与真实子代理。当前保留标志回退，目录到达后自动纠正，不凭名称或工具猜测。
- **快照没有每源错误标志。** 服务端各来源读取异常会回退空数组、null、false 等值，成功 GET 无法证明每个来源均读取成功。
- **跨页面客户端遥测未由这三个 GET 提供。** 连接页面列表只说明服务端流登记，无法读取其他聊天页的内存、心跳接收、重连、lease、watchdog 或浏览器连接池压力；不显示虚构的零值或正常状态。
- **普通任务缺少统一完整轮次契约。** wrapper 生命周期、最近事件／命令、子代理运行和通知不构成普通任务完整执行记录，不能据此判定完成或成功。
- **Debug 快照不含全局定时器及通用跨会话交接清单。** wakeups 已有独立只读查询 API，包含任务、实际 armed 状态及 health；本页尚未接入；该模块的清单也不能替代任意扩展的活动定时器清单，接入不属于当前页面的三接口边界。

## 验收入口

可执行命令、接入位置及升级检查集中于 [AGENTS.md](AGENTS.md#验证)。验收覆盖信息分区、只读网络边界、空／未知／过期／失败语义、家族与侧聊身份、模型／资源／时钟隔离、退出清理、真实倒计时、桌面与手机滚动、三语言、复制及减少动态效果。浏览器使用响应夹具，不代表真实模型、用户任务或部署产物验收。
